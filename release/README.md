# ResearchOS Windows releases

The versioned NSIS installers and standalone executables are copied here from verified Tauri release builds. Verify files
against `SHA256SUMS.txt` before distribution. These builds are unsigned; Windows may show a SmartScreen warning.

The current release is v0.11.0 with a Simplified Chinese interface, the Research Problem Atlas (科研常见问题库), and the
Chinese first-run tutorial. Chinese release notes: `RELEASE_NOTES_v0.11.0.md`. The v0.9.0 artifacts are retained for rollback
and were not overwritten. v0.10.0 is retained for audit but is superseded due to its blank-screen browser-bundle defect and
should not be distributed.
Reproducible version, toolchain, schema, size, and digest information is recorded in `BUILD_METADATA_v0.11.0.json`.
