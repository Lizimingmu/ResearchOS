# ResearchOS Windows releases

The versioned NSIS installers and standalone executables are copied here from verified Tauri release builds. Verify files
against `SHA256SUMS.txt` before distribution. These builds are unsigned; Windows may show a SmartScreen warning.

The current release is v0.10.2 with a Simplified Chinese interface. The v0.9.0 artifacts are retained for rollback and were not overwritten. v0.10.0 is
retained for audit but is superseded due to its blank-screen browser-bundle defect and should not be distributed.
Reproducible version, toolchain, schema, size, and digest information is recorded in `BUILD_METADATA_v0.10.2.json`.
