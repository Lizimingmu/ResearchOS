# ResearchOS v0.12.0 发布说明（中文）

发布日期：2026-08-26　·　状态：**候选版本（release candidate）**　·　本构建**未签名**；下表哈希为对发布文件重新计算的 SHA256，不代表任何发布者签名。

## 本版重点：个人内容工作台（M015）

- **内容工作台（内容库 / 草稿 / 待审核 / 发布箱 / 版本历史 / 冲突）**：为个人新增内容提供稳定 ID、修订号、SHA-256 哈希与依赖闭包管理。
- **内置内容的版本化修订**：通过受控 overlay 修订内置内容——模板创建、复制、编辑、筛选、确定性校验（证据缺口、依赖影响）、修订包导入（干跑字段 diff、过期基线冲突、全有全无原子应用）、版本比较与回滚。内置基线保持只读；应用升级产生冲突而非静默覆盖。
- **审核包导出**：所选内容连同依赖闭包导出为固定 5 个文件的审核包（manifest / content / REVIEW_COPY / SCIENTIFIC_CHANGESET / dependencies），供 Codex/OpenScience 审阅，无需扫描整个仓库。
- **显式策划式 Obsidian 发布**：
  - 仅允许配置一个专用子文件夹；连接验证只读，不创建、不修改任何文件；
  - 发布前列出精确的 create/update/conflict/unchanged 文件清单，默认每批最多 20 条笔记，超出需第二次确认；
  - 永久笔记使用稳定 `researchos_id` 与受管块：重复发布不产生重复文件（未变化即零写入），标题改名跟随稳定 ID，用户手写区逐字节保留；
  - 受管块被外部改动时产生冲突并整批零写入；
  - 可选的有限 `_Review/<batch-id>` 审核往返：审核意见转为待核验的修订候选。无监听器、无自动拉取/合并/发布——连接、预览或取消都不会写文件。
- **边界保持**：草稿/待审/归档/弃用/被取代内容绝不进入今日学习、复习、搜索或发布；本地私人启用后仍显示"待核验"——启用使用与科学核验是两个独立动作。
