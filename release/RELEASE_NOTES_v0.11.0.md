# ResearchOS v0.11.0 发布说明（中文）

发布日期：2026-08-25 · 界面语言：简体中文（zh-CN）· 状态架构：3 · SQLite user_version：2

## 本次新增

- **科研常见问题库（Research Problem Atlas）**：八种诊断训练模式（快速定位 / 鉴别诊断 / 序贯排查 / 缺失信息 / 错误定位 / 结论边界 / 审稿诊断 / AI 解释审核）；中英文、缩写、别名的确定性搜索；来源注册库、证据主张映射、知识版本标记；事务性源包导入（先 dry-run、双门禁、冲突全有或全无）。
- **约五分钟中文首次教程**：依次介绍 今日学习 → 科研常见问题库 → 待核验证据状态 → 先锁定再反馈 → 复习与迁移。可随时跳过，可在 设置 → 常规设置 中重新打开；支持键盘（← 上一步，→ / Enter 下一步，Esc 跳过）、焦点管理与减动效。教程练习运行在隔离预览状态，不会写入任何学习记录。

## 导入与证据安全

- 更严格的源包校验：异常安全、结构化错误（代码 + 位置）、超长字段确定性拒绝；结构有效性与科学完整性为两道独立门禁；未分类（`unclassified`）卡片永不具备导入资格。
- 外部 166 张遗留卡片保持 `unclassified`、待核验、禁止导入；演示内容全部保持 `pending`，待核验主张显示"拟直接支持 · 待核验"。
- 来源层级采用 Codex 审定的 S/A/C 映射；徽章不是证据，标识符解析不等于主张被证实。

## 验证摘要

- 前端测试 50/50；Rust 测试 7/7；source-pack / Problem Atlas / staging（63/63）/ content / localization / performance / startup / seed / handoff 门禁全部通过。
- 状态架构 3、SQLite user_version 2 不变；v0.10.2（schemaVersion 2）状态可迁移升级。
- 备份/恢复：文件级往返校验逐字节一致（副本上验证）；SQLite 备份导出/导入命令另有 Rust 测试覆盖。
